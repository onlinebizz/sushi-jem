Drop real files here. The page picks them up with no code changes.

logo.svg or logo.png   The restaurant's real logo. It replaces the placeholder mark in the header, footer and browser tab.
                       If the logo file already contains the name, set logoHasName to true in the settings block of index.html.
dish-1.jpg to dish-3.jpg
                       Photos for the three featured dishes (creamy rolls, spicy noodles, bento). Square crops work best.
menu-1.jpg to menu-4.jpg
                       Photos or scans of the owner-approved printed menu. They show in the Menu section automatically.
gallery-1.jpg to gallery-6.jpg
                       A "Moments at Jem" gallery appears once at least 3 of these exist.

For a typed, priced menu, fill the "menu" list in the settings block of index.html (an example of the format is in the comment above it).

Use photos. Photos posted by customers in Google reviews are ok to showcase.
